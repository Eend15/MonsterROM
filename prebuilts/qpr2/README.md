GSI in CRB. SOURCES.json records each original path and checksum. Two complete
APEX containers retain their original Google container and AVB signatures.

The SDK-37 Paradigm profile checks source and retained-provider hashes before
using these files. No private signing keys, whole GSI or firmware backup is
included. This is not a complete Android platform replacement or a Samsung
Knox upgrade. Source partitions and the connected phone are not modified.
